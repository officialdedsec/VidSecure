# Changelog

All notable changes to VidSecure are documented here.

## [1.0.0] — 2026
### Added
- **VidSecure Protector (Windows):** AES-256 video encryption, per-device & password
  licensing, branded player generation, one-click installer builder, key generator,
  encrypted machine-locked records, expiry, play-limit, watermarking, anti-capture &
  anti-tamper, internet policy, pre-play/end pop-ups.
- **VidSecure Player (Windows):** frameless branded player, in-memory decryption,
  license manager, anti-reverse-engineering.
- **VidSecure Player (Android 8+):** full compatibility with Windows-encrypted files,
  device Hardware ID for key generation, in-memory decryption, FLAG_SECURE
  anti-capture, anti-mirroring, anti-root/Frida/emulator/clone, moving watermark,
  expiry & one-time-play, internet policy, in-app pop-ups, VLC-style gesture controls,
  license manager, and ad support.

_Released free to use by the Dedsec Cyber Security Research Institute._
