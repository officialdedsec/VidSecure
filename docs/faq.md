# FAQ

**Is it really free?**
Yes — free to use for personal and commercial content protection. See the LICENSE.

**Does it need the internet?**
No. Encryption and playback are fully offline. You can optionally *require* the
viewer to be online or offline per file.

**Can one key unlock a whole course?**
Yes. A single key or password can unlock a batch of videos on a device.

**What if my customer reinstalls Windows or changes their phone?**
Enable **Hardware Swipe** when encrypting so their key survives OS reinstalls and
hardware changes. A new device needs a new key.

**Which video formats are supported?**
Common formats (MP4/MKV/etc.). The player decrypts and plays the stream in memory.

**Can I brand the player as my own?**
Yes — name, icon, colours, logo, splash, watermark, and your own file extension.

**Is it unbreakable?**
No client-side DRM is. VidSecure removes the easy copy, locks files to devices,
blocks common capture tools, and watermarks leaks so they're traceable. Treat it as
strong, layered protection — not a magic guarantee.
